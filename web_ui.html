Check chapter list

reads the page, walks nothing
Fetches a comic's archive page and says what it would be read as: how many chapters, what each is called, and which page each starts at. It downloads nothing and changes nothing, so it is the cheap way to find out whether a page is usable before committing a comic to it. Chapter boundaries

Where each chapter starts, as the archive page or the comic's own addresses were read. A site that names one page oddly - a cover called 20-the-sovereign where every other is issue-20-cover - puts a boundary in the wrong place, and no rule can tell. Change one here and it is written down as a correction: working the chapters out again, from a fresh reading of the archive or of the addresses, keeps it. Renaming a chapter to one that is already there moves that chapter to the new page instead of adding a second of the same name. A comic whose chapter archives are already written has the ones that changed written again on the spot, since an archive holding a boundary you just corrected is a wrong archive.
